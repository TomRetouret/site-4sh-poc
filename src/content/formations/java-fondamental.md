Java est un langage de programmation multi-plateforme et orienté objet. Il est largement utilisé aujourd'hui, dans le top 5 de l'indice Tiobe.

C'est un langage en évolution permanente avec un écosystème très riche. Il permet de développer rapidement des applications fiables et sécurisées : applications mobiles Android, applications d'entreprise, applications cloud et big data, applications web, desktop ou IoT.

Cette formation Java a pour objectif de permettre à des développeurs de découvrir les fondamentaux du langage, ainsi que les outils essentiels pour leur permettre à leur tour de développer des applications de qualité.

La formation s'appuie sur des éléments théoriques mais également des démonstrations et des travaux pratiques pour assurer une maîtrise complète des concepts fondamentaux de ce langage.
