La formation Git - Les fondamentaux est conçue pour enseigner l'utilisation efficace de Git, un système de contrôle de version décentralisé (DVCS) orienté vers la rapidité, l'efficacité et la légèreté. En permettant la gestion de gros projets avec une grande souplesse dans le workflow de contribution, Git est devenu incontournable dans le domaine du développement logiciel.

Les participants apprendront à initialiser et configurer Git et l'utiliser au quotidien, mettre en place différents dépôts, maîtriser les principales structures de données manipulées par Git (commit, blob, graphe), gérer les branches du projet, résoudre les conflits lors de la mise en commun des développements, partager leurs changements avec les autres membres de l'équipe et parcourir le graphe Git.

Que vous soyez développeur, designer, Product Owner ou rédacteur de documentation, la formation Git vous permettra de collaborer efficacement sur vos projets tout en garantissant une gestion optimale du code source. Nous proposons également une formation Git - Avancé pour ceux qui souhaitent se perfectionner.
