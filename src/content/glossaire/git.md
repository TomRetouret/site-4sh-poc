---
terme: "Git"
definition: "<a href='/formations/git-fondamental/'>Git</a> est le système de gestion de versions le plus répandu pour le code source. Il conserve l'historique de toutes les modifications, permet à plusieurs personnes de travailler en parallèle et de revenir à un état antérieur en cas de problème. C'est un outil de base du travail en équipe sur un projet logiciel."
