---
terme: "API"
definition: "Une API (interface de programmation) est un ensemble de règles qui permet à deux logiciels de communiquer et d'échanger des données. Elle expose des fonctions d'un système à d'autres applications sans en dévoiler le fonctionnement interne. Les API sont essentielles pour connecter un logiciel à des services tiers ou à des applications mobiles."
