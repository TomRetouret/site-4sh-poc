---
terme: "Angular"
definition: "<a href='/expertises-techniques/angular/'>Angular</a> est un framework open source développé par Google pour construire des applications web dynamiques en TypeScript. Il structure le code en composants réutilisables et gère l'affichage, la navigation et les échanges avec les serveurs. C'est l'un des socles techniques utilisés pour développer des interfaces riches et maintenables."
