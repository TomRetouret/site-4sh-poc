Java, c'est une histoire longue chez nous, pas une ligne sur un CV commercial.

### Plus de 15 ans d'expérience sur des projets Java critiques

Depuis 2007, nous livrons des applications Java au cœur des systèmes d'information de nos clients. Cette ancienneté nous vaut une vraie légitimité dans la communauté : le Bordeaux Java User Group a été fondé en 2009 par Xavier Hanin, directeur technique et associé de 4SH.

### Maîtrise des versions modernes

Nous travaillons sur les versions récentes et LTS de Java, en fonction des contraintes techniques de chaque projet. Records, pattern matching, API récentes : nous exploitons ce que le langage a gagné, sans laisser traîner de dette technique.

### Une stack technique éprouvée

Spring Boot, Hibernate, Jakarta EE côté applicatif, Maven et Gradle pour le build, JUnit pour les tests. C'est une stack que nos développeurs pratiquent au quotidien, pas un empilement d'outils choisis pour la démo.

### Une intégration à vos environnements DevOps

Vos applications Java s'intègrent à vos chaînes existantes : conteneurisation avec Docker, orchestration avec [Kubernetes](/expertises-techniques/kubernetes/), déploiement continu en CI/CD. Le code livré est fait pour être exploité, pas seulement pour compiler.

## Quels types d'applications développons-nous en Java ?

Java couvre un large spectre de besoins d'entreprise. Voici les projets sur lesquels nous intervenons le plus.

### Logiciels métiers et back-offices

Java excelle sur les [logiciels métier sur mesure](/prestations/logiciel-metier/) et les back-offices qui structurent votre activité : gestion, traitement des données, automatisation des flux.

### Applications SaaS multitenant

Pour une [application SaaS](/prestations/application-saas/) multitenant, Java apporte la solidité et la sécurité qu'exige une plateforme partagée entre plusieurs clients.

### API REST et microservices

Nous développons des API REST et des architectures en microservices, prêtes pour le cloud, faciles à faire évoluer service par service.

### Modernisation et migration d'applications legacy

Vous avez une application J2EE ou en Java 8 qui vieillit ? Nous la modernisons et la migrons vers une version LTS récente, sans casser ce qui fonctionne.

## Notre méthodologie de développement Java

### Cadrage et architecture technique

Nous commençons par le cadrage et les choix d'architecture : découpage, modèles de données, intégration au système d'information. Les bonnes décisions se prennent avant la première ligne de code.

### Développement agile et revues de code

Nous développons en agile, avec des revues de code systématiques. Un regard croisé sur chaque contribution, c'est la façon la plus simple de tenir la qualité dans la durée.

### Tests automatisés

Nos développements sont couverts par des tests automatisés : JUnit, Mockito, TestContainers. Vous livrez avec un filet, vous faites évoluer sans casser l'existant.

### Déploiement continu et MCO

Nous mettons en place le déploiement continu et assurons le [maintien en conditions opérationnelles](/prestations/hebergement/), pour que votre application reste disponible et à jour après la mise en production.
