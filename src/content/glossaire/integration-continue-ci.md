---
terme: "Intégration continue (CI)"
definition: "L'intégration continue consiste à fusionner et tester automatiquement les modifications de code dès qu'elles sont produites. Chaque changement déclenche une vérification (compilation et tests) qui signale rapidement les régressions. Cette pratique limite les mauvaises surprises et maintient une base de code toujours saine."
