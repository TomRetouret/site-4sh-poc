L’arrivée des agents de code basés sur les grands modèles de langage (LLM) transforme en profondeur le métier de développeur. Bien utilisés, ces outils permettent d’accélérer significativement le développement tout en maintenant, voire en améliorant, la qualité du code produit. Mal utilisés, ils génèrent du code difficile à maintenir et donnent une fausse impression de productivité.

La formation Développeur augmenté par l’IA est conçue pour les développeurs souhaitant intégrer efficacement les agents de code IA dans leur pratique quotidienne. Elle aborde d’abord les fondamentaux à travers le développement d’un nouveau projet : interaction avec l’agent, structuration du contexte, workflows de développement et contrôle de la qualité. Elle traite ensuite le cas le plus fréquent en entreprise : intervenir sur un projet existant volumineux, dont on connaît l’architecture globale, en s’appuyant notamment sur les rules, la gestion du contexte et les techniques adaptées aux grandes bases de code.

La formation s’appuie sur des éléments théoriques mais également des démonstrations et des travaux pratiques pour assurer une maîtrise complète du développement augmenté par l’IA.
