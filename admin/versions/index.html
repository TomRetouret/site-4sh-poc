Revenir à une version publiée

Choisissez une page ou une fiche, comparez une ancienne version avec celle en ligne, puis restaurez-la. La version restaurée devient un brouillon dans le back-office : elle sera relue puis publiée comme toute autre modification. Le site ne change pas avant la publication.
