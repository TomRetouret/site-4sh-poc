Git est un logiciel de gestion de version décentralisé. Son usage est extrêmement répandu, que ce soit dans le monde de l’industrie comme celui de l’open source. C’est un outil très puissant, utilisé au quotidien, mais qu’il convient de maîtriser, pour éviter d’en faire un mauvais usage.

Cette [formation en informatique](/formations/) a pour but de présenter Git, ses fonctionnalités et son utilisation quotidienne.

La formation Git essentiel se déroule en alternant entre une partie théorique et des travaux pratiques. Aller plus loin avec notre [formation Git les fondamentaux](/formations/git-fondamental/).
